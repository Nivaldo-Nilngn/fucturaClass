# Instruções do Core Dev Bundle
Ao escrever qualquer tipo de código, siga estas regras fundamentais:
1. **Código Limpo:** Priorize a legibilidade humana. O código é lido muito mais vezes do que é escrito.
2. **Documentação e Comentários:** Comente apenas o "porquê" (motivo) e não o "o quê" (o que o código faz). Escreva docstrings detalhadas para APIs públicas.
3. **Padrões de Nomenclatura:** Utilize as convenções padrão da linguagem (camelCase, snake_case, PascalCase, etc).
4. **Gerenciamento de Estado Previsível:** Evite mutação de estado desnecessária e prefira variáveis imutáveis sempre que possível.
