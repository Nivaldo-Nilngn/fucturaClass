# Instruções do Frontend Design Expert
Ao trabalhar com Frontend, siga estas diretrizes de design:
1. **Estética Premium:** Utilize esquemas de cores modernos, fontes legíveis e espaços consistentes (padding/margin).
2. **Micro-interações:** Adicione animações sutis e feedbacks visuais em botões, links e carregamentos.
3. **Responsividade:** Garanta que o layout se adapte perfeitamente a telas de celulares, tablets e desktops.
4. **Acessibilidade:** Utilize tags semânticas, atributos ARIA e bom contraste de cores.
