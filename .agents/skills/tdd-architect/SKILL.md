# Instruções do TDD Architect
1. **Test-Driven Development:** Sugira a escrita de testes unitários e de integração antes de implementar a lógica de negócios complexa.
2. **SOLID:** Aplique os princípios SOLID (Responsabilidade Única, Aberto/Fechado, Substituição de Liskov, Segregação de Interface, Inversão de Dependência).
3. **Arquitetura Desacoplada:** Mantenha a camada de regras de negócio independente da interface, do banco de dados e de frameworks.
